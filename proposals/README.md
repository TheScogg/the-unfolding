# Proposals

Proposals let the tradition change without hiding its disagreements. A proposal is not adopted merely because it appears in this directory.

## Statuses

**Draft → Discussion → Accepted, Deferred, Withdrawn, or Rejected.**

A status change needs a dated decision record and rationale. Rejection of a proposal does not prevent an independent adaptation under the applicable license.

## Process

1. Begin with a Discussion explaining the idea.
2. Copy [TEMPLATE.md](TEMPLATE.md) into a numbered file and open a pull request.
3. Say whether it changes a shared commitment, adds an optional practice, or develops one interpretation.
4. Record objections, alternatives, consent questions, and practical implications.
5. Follow the review periods and decision process in [GOVERNANCE.md](../GOVERNANCE.md).
6. If accepted, update the relevant source documents and changelog. Preserve the proposal and its decision record.
