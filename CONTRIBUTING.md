# Contributing

Help shape Church of the First Gift, its origin story The Unfolding, and its shared practices.

Thank you for helping this tradition become more thoughtful, useful, and accessible. You can contribute without writing code or adopting a religious belief.

## Ways to help

- Improve wording, translations, accessibility, and navigation.
- Write optional rituals, poems, music, art, or reflections.
- Explain a disagreement fairly, including the strongest version of the position you oppose.
- Try a practice voluntarily and describe what helped or did not help.
- Suggest clearer governance, accountability, or ways to participate without GitHub.

## Choose the right place

Use Discussions for an open question. Use an issue for an actionable problem. Use a pull request for a concrete change. Substantial theological, ritual, or governance changes begin with the [proposal process](proposals/README.md).

When proposing something, explain:

1. What is changing?
2. Why would it help?
3. Is it a shared commitment, an optional practice, or one interpretation?
4. What objections or alternatives should readers consider?

## Editing the repository

1. Fork the repository and create a branch.
2. Edit the Markdown source, preserving readable paragraphs and relative links.
3. Link the relevant issue or discussion in your pull request.
4. Describe any changed meaning. A fluent rewrite can still change a teaching.
5. Check internal links and confirm any new media opens correctly.

For a small correction, GitHub's browser editor is sufficient. If GitHub is unfamiliar, describe the change in a Discussion or issue; a maintainer can help turn it into an edit. No response time is guaranteed during this founding stage.

## Editorial commitments

Distinguish shared commitments from optional beliefs. Do not present theological speculation as scientific evidence. Describe other communities in their own terms and invite their review before claiming an agreement with them. Do not remove a documented disagreement simply to make the tradition look unanimous.

Do not publish a person's story, photograph, contact details, or religious identity without their permission. Public repository history can preserve material after an edit.

## Rights and AI assistance

Read [LICENSE.md](LICENSE.md). Submit only material you can contribute under the applicable license. Identify third-party sources, permissions, and any exceptions clearly. Do not add proprietary font files.

AI assistance is welcome when disclosed in the pull request. The contributor remains responsible for checking facts, citations, permissions, and meaning. No model output has spiritual authority by virtue of being generated.

Participation is subject to the [code of conduct](CODE_OF_CONDUCT.md). Publication decisions follow [governance](GOVERNANCE.md). A rejected edit is not a judgment of anyone's worth or freedom to hold a belief.
